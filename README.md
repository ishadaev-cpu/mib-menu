# Табло меню столовой МИБ 3

Страница для ТВ-экрана в столовой. Меню дня берётся из Saby автоматически.

- `fetch_menu.py` — каждые 5 минут (пн–пт, 06:00–17:00 МСК) забирает прайс дня из Saby и пишет `docs/menu.json`.
  Неделя цикла считается сама: неделя с 02.11.2026 — Н1, дальше Н2, Н3, снова Н1.
- `docs/index.html` — само табло. До 11:00 показывает завтрак, после — обед. Обновляет меню каждые 2 минуты.
  Принудительно: `…/#zavtrak` или `…/#obed`.
- Если в какой-то день меню из другой недели — создайте `docs/override.json`: `{"2026-11-05": "Н2 четверг нов"}`.

Ключи Saby хранятся в Settings → Secrets → Actions: `SABY_APP_ID`, `SABY_APP_SECRET`, `SABY_SECRET_KEY`.
